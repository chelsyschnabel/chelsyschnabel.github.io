  • High Low

    GitHub · Scratch

    A card game that can be used for several kinds of instruction, including teaching probability in mathematics or loops, conditions, and functions in programming. Versions are provided for programming (Python or R) and for probability.

    Tools: GitHub, RStudio, Python 3.12 and IDLE, Microsoft Word for the probability versions and card decks, Scratch for the online version, and Figma for the cover image and Scratch character artwork.

    • 9-12

    Teacher files and remote options

    Teacher edition: probability

    A teacher edition for teaching this lesson as a probability lesson, with scorecards for students to compute the probability of each turn. It's the same file provided in the repository's probability folder.

    High Low Instructions (.docx)

    Card files

    • Student deck, cards 1 through 9 (.docx): print one for each student.
    • Teacher demonstration deck (.docx): print twice, and add magnets to the back if you have a magnetic board.

    Teaching remotely

    A live session works best, so students can interact with one another. The facilitator guide for the High Low Live Workshop in the repository has suggestions for running it. It's based on the R version but adapts to the probability and Python versions. For an online way to play, the Scratch version gives students another way to think about conditions and loops.

    Updated October 26, 2026: probability version and card files added, a new Python version, and the repository reorganized by version. The project moved from Posit Cloud to GitHub for easier access.

  • Polygon Sort

    Polypad

    A Polypad activity based on Illustrative Mathematics Grade 2, Unit 6, Lesson 1. Students drag the shapes into their correct drop zones, which check answers automatically as students work.

    I recommend the teacher project this manipulative to lead conversations while students work with the physical cards, since clicking and dragging can be hard for this age group on some devices.
